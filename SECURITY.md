# Security

RUSHplify is early-alpha software for private use.

RUSHplify only connects to HeadRush devices on the local network (`.local`, loopback or private-LAN
addresses). HeadRush Cloud and TONE3000 sign-in run through the pedal; RUSHplify stores no credentials.

Review and redact diagnostics before sharing them. See [PRIVACY.md](PRIVACY.md).
